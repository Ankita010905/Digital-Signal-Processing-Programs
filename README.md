# Digital-Signal-Processing-Programs

This repository contains the programs and practical implementations completed as part of the **Digital Signal Processing (DSP)** course.

The programs cover fundamental concepts of discrete-time signals, systems, signal generation, convolution, correlation, transforms, filtering, and other DSP techniques.

---

# Programs Included

## Signal Generation

* Generation of discrete-time signals
* Unit impulse signal
* Unit step signal
* Ramp signal
* Sinusoidal signals
* Other basic discrete-time signals

## Signal Operations

* Addition of signals
* Multiplication of signals
* Time shifting
* Time scaling
* Time reversal
* Other basic signal operations

## Convolution

* Linear convolution
* Circular convolution
* Convolution using MATLAB
* Comparison of linear and circular convolution

## Correlation

* Auto-correlation
* Cross-correlation
* Correlation of discrete-time signals

## Fourier Transform

* Discrete Fourier Transform (DFT)
* Inverse Discrete Fourier Transform (IDFT)
* Fast Fourier Transform (FFT)
* Inverse Fast Fourier Transform (IFFT)
* Magnitude and phase spectrum

## Z-Transform

* Z-transform
* Inverse Z-transform
* Pole-zero analysis
* Region of convergence

## Digital Filters

* FIR filter
* IIR filter
* Low-pass filter
* High-pass filter
* Band-pass filter
* Band-stop filter
* Filter response analysis
